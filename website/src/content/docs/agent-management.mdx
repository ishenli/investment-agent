## 概述

Agent 管理是 Investment Agent 的智能体记忆与档案管理中心。通过 **运行时资产编辑器**，你可以直接管理 Claude Code 和 Hermes Agent 在运行时使用的持久化信息——包括智能体记忆（MEMORY.md）和用户档案（USER.md），帮助智能体更好地学习和适应你的投资需求。

### 资产存储位置

- **Claude Code**：资产存储在 `workspace/{userId}/` 目录
- **Hermes Agent**：资产存储在 `workspace/{userId}/.hermes/memories/` 目录
- **MEMORY.md**：记录智能体的持久化记忆（最大 2200 字）
- **USER.md**：记录用户档案信息（最大 1375 字）

## 资产类型说明

| 资产 | 目的 | 存储位置 | 容量限制 |
|------|------|---------|----------|
| **MEMORY.md** | 记录智能体学到的信息、发现的规律、用户的偏好等 | `workspace/{userId}/` | 2200 字 |
| **USER.md** | 定义用户的投资背景、风险偏好、约束条件等 | `workspace/{userId}/` | 1375 字 |

## 使用场景

### 1. 记忆学习
定期更新 MEMORY.md，让智能体记住：
- 之前分析过的行业趋势
- 发现的投资机会和陷阱
- 对你投资风格的洞察

### 2. 用户档案
在 USER.md 中描述：
- 你的投资目标和时间跨度
- 风险承受能力和禁区
- 重点关注的行业或公司

### 3. 多运行时同步
 Claude Code 和 Hermes Agent 可共享相同的记忆和档案，实现一致的投资决策。
