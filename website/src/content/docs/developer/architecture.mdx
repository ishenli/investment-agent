## 核心组件

### 智能体引擎

智能体引擎编排 AI 工具并管理对话上下文：

- **引擎接口**：多个 AI 后端的统一 API
- **工具注册表**：动态工具注册和执行
- **上下文管理器**：会话和对话状态管理
- **响应格式化器**：多模态输出处理

### 数据层

基于 SQLite 的存储，使用 Drizzle ORM：

- **投资组合数据库**：持仓、交易、账户
- **知识库**：带嵌入向量的投资笔记
- **可观测性存储**：追踪、跨度、指标

### 可观测性系统

为每次智能体执行提供全面追踪：

- **追踪收集**：分层跨度记录
- **指标聚合**：Token 统计、延迟、工具调用
- **成本计算**：按模型定价表计算
- **可视化**：聊天内置侧边栏，时间线视图
