## Hermes 引擎

轻量级智能体引擎，专注于**可观测性**和**快速响应**。

### 核心特性

- **完整事件追踪**：每次工具调用、Token 使用、延迟都有详细记录
- **实时指标面板**：在聊天界面直接查看执行过程
- **成本追踪**：基于模型定价表精确计算每次对话成本
- **技能系统集成**：自动加载用户自定义技能

### 内置工具

| 工具 | 说明 |
|------|------|
| `read_file` | 读取本地文件 |
| `search_files` | 搜索文件内容 |
| `list_directory` | 列出目录结构 |
| `web_search` | 网络搜索 |
| `web_fetch` | 获取网页内容 |
| `think` | 思考工具，用于推理 |

### 业务工具

Hermes 引擎自动加载所有业务工具：

- **资产查询**：股票、基金、黄金价格
- **笔记管理**：创建、搜索、更新投资笔记
- **数据库查询**：自然语言转 SQL
- **交易记录**：查询历史交易和账户余额
- **组合分析**：投资组合统计

### 权限控制

Hermes 引擎内置工具权限管理系统，通过**权限等级 × 工具类别**的策略矩阵控制工具执行行为。

#### 权限等级

| 等级 | 说明 |
|------|------|
| `safe` | 安全模式，所有工具调用均需用户确认 |
| `auto` | 自动模式（默认），敏感操作需确认，常规操作自动执行 |
| `full-access` | 完全访问，所有工具自动执行 |

#### 工具类别

每个工具在注册时声明所属类别：

| 类别 | 说明 | 示例工具 |
|------|------|----------|
| `read` | 只读操作 | `read_file`、`list_directory`、`web_search` |
| `write` | 写入操作 | `write_file`、`note_create` |
| `system` | 系统操作 | `note_delete`、`execute_command` |
| `finance` | 金融操作 | `execute_trade`、`transfer_funds` |

#### 策略矩阵

权限等级与工具类别的组合决定执行策略（`auto` / `confirm` / `deny`）：

| | read | write | system | finance |
|------|------|-------|--------|---------|
| **safe** | confirm | confirm | confirm | confirm |
| **auto** | auto | auto | confirm | confirm |
| **full-access** | auto | auto | auto | auto |

- `auto`：直接执行，无需确认
- `confirm`：暂停执行，等待用户在聊天界面点击确认或拒绝
- `deny`：拒绝执行（保留策略，当前未启用）

#### 确认流程

当策略为 `confirm` 时，引擎通过 SSE 事件向前端发送确认请求，用户可在聊天界面中看到权限确认卡片，点击"允许"或"拒绝"。超时 30 秒未响应将自动拒绝。

```
用户发送消息 → LLM 决策调用工具 → 查询策略矩阵
  → auto: 直接执行
  → confirm: 发送 SSE 事件 → 前端弹出确认卡片 → 用户决策 → 执行或跳过
```

### 适用场景

- 需要详细追踪执行过程
- 调试和开发新工具
- 成本敏感的应用
- 快速迭代原型

## Claude 引擎

集成 Anthropic Claude Agent SDK，提供**顶级推理能力**。

### 核心特性

- **高质量推理**：Claude 3.5 Sonnet/Opus 模型
- **文件附件支持**：直接分析 PDF、图片等文件
- **MCP 服务器集成**：扩展工具生态
- **权限控制**：code/plan/ask 三种模式

### 文件支持

支持多种文件类型作为上下文：

```typescript
files: [
  {
    name: "report.pdf",
    data: fileBuffer,
    type: "application/pdf"
  },
  {
    name: "chart.png", 
    data: imageBuffer,
    type: "image/png"
  }
]
```

### 权限模式

| 模式 | 说明 |
|------|------|
| `code` | 自主编码模式，自动执行工具 |
| `plan` | 规划模式，先制定计划再执行 |
| `ask` | 询问模式，每个操作需确认 |

### 适用场景

- 复杂推理和代码分析
- 需要理解文件内容
- 多步骤决策场景
- 对质量要求高的任务

## DeepAgents 引擎

基于 LangChain/LangGraph 的**工作流编排引擎**，专为投资顾问设计。

### 核心特性

- **图结构编排**：复杂任务分解为多个节点
- **状态管理**：跨步骤的状态保持
- **条件分支**：根据中间结果动态决策
- **并行执行**：独立节点可并行处理

## 引擎对比

| 特性 | Hermes | Claude | DeepAgents |
|------|--------|--------|------------|
| **响应速度** | 快 | 中 | 慢 |
| **推理质量** | 高 | 极高 | 高 |
| **可观测性** | 完整 | 基础 | 详细 |
| **成本追踪** | ✓ | ✓ | ✓ |
| **文件支持** | ✗ | ✓ | ✗ |
| **权限控制** | 策略矩阵 | code/plan/ask | ✗ |
| **自定义技能** | ✓ | 通过 MCP | ✓ |
| **工作流编排** | 简单 | 中等 | 复杂图结构 |
| **最佳场景** | 快速迭代 | 复杂分析 | 投资顾问 |

## 如何选择

**快速开发** → 选择 **Hermes**  
完整的可观测性帮助你快速调试和迭代

**高质量输出** → 选择 **Claude**  
顶级推理能力，适合复杂的分析和代码任务

**投资咨询** → 选择 **DeepAgents**  
专为投资顾问设计，工作流完整

## 配置使用

```typescript
// 默认引擎配置
{
  "defaultEngine": "hermes"
}

// 运行时切换引擎
const response = await agent.execute({
  engine: "claude",
  model: "claude-3-5-sonnet-latest",
  messages: [...]
});

// DeepAgents 投资顾问
const advisor = await investmentAdvisorAgent.chat({
  messages: [...],
  accountId: "user_123",
  model: "gpt-4-turbo"
});
```
