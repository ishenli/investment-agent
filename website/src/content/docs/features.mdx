## AI 智能分析工具

投资助手在聊天中为你提供以下分析能力：

- **资产信息查询**：通过 Finnhub 获取实时股票、基金和黄金价格
- **生成式 UI 卡片**：在聊天消息中展示股票行情、基金详情、数据图表和交易意图确认
- **投资笔记搜索**：对投资笔记进行语义搜索，快速找到相关研究
- **自然语言数据查询**：用中文提问投资组合数据，自动转换为 SQL
- **市场研究**：基于 Tavily 的实时网页搜索与行业研究
- **技术指标分析**：股票图表、技术指标和市场情绪分析

详见 [生成式 UI](/generative-ui/)。

## 权限与安全

<CardGrid>
  <Card title="灵活的权限控制" icon="shield">
    三级权限模式：`safe`（全部确认）、`auto`（智能判断）、`full-access`（全部自动）。
  </Card>
  <Card title="实时操作确认" icon="approve-check">
    敏感操作在聊天界面弹出确认卡片，用户一键批准或拒绝。
  </Card>
</CardGrid>

**权限控制特性：**
- **工具分类策略**：按工具类型分级（只读、写入、系统、金融），精细控制执行行为
- **实时通知**：工具需要确认时，通过 Server-Sent Events 推送到前端
- **超时保护**：30 秒未响应自动拒绝，防止流程阻塞
- **灵活切换**：用户可在聊天界面随时调整权限等级

完整的权限控制说明请参阅 [工具权限与安全](/permissions/)。

# 技术架构

<CardGrid>

  </Card>
</CardGrid>

## 可观测性与监控

<CardGrid>
  <Card title="分层追踪系统" icon="activity">
    为每次智能体执行提供分层追踪，支持显式上下文传递。
  </Card>
  <Card title="实时指标面板" icon="graph">
    Token 使用量、延迟、工具调用次数、迭代统计等实时展示。
  </Card>
  <Card title="成本分析" icon="calculator">
    基于模型定价表的会话成本明细和趋势分析。
  </Card>
</CardGrid>

**可观测性特性：**
- **完整追踪数据**：在聊天侧边栏查看追踪时间线、跨度详情和聚合指标
- **历史分析**：追踪/跨度数据持久化到 SQLite，支持历史回溯和分析
- **成本透明**：每次对话的 AI 调用成本完全可见，助力预算规划
