## 安装与配置

### 支持哪些操作系统？

Investment Agent 桌面应用目前仅支持：
- **macOS** 11+ (Intel 和 Apple Silicon)

<details>
<summary>**其他平台支持计划**</summary>

Windows 和 Linux 平台支持正在规划中，目前可以通过 Web 应用方式在其他操作系统上使用。

Web 应用支持所有主流操作系统，只需运行源码即可：
```bash
pnpm dev
# 访问 http://localhost:3000
```
</details>

### Node.js 版本要求？

建议使用 Node.js 18+ 或 Node.js 22+ (推荐)。可以使用 nvm 或 fnm 管理多版本：

```bash
# 使用 nvm 安装
nvm install 22
nvm use 22
```

### 安装依赖很慢怎么办？

推荐使用国内镜像：

```bash
# 设置 pnpm 镜像
pnpm config set registry https://registry.npmmirror.com

# 或使用环境变量
npm_config_registry=https://registry.npmmirror.com pnpm install
```

### 如何选择引擎？

| 引擎 | 适用场景 |
|------|---------|
| **DeepAgents** | 复杂多步骤任务、需要状态管理 |
| **Claude** | 高质量推理、代码分析 |
| **Hermes** | 轻量快速、可观测性要求高 |

### 如何切换引擎？

```typescript
// 配置文件中设置默认引擎
{
  "defaultEngine": "claude"
}

// 或在对话时指定
const response = await agent.execute({
  engine: "hermes"
});
```

## 数据与隐私

### 数据存储在哪里？

所有数据存储在本地 SQLite 数据库，不会上传到云端：

```
data/
├── investment.db    # 投资数据
├── knowledge.db     # 知识库
└── observability.db # 追踪数据
```

### 如何备份数据？

```bash
# 备份所有数据
cp -r data/ backup/data_$(date +%Y%m%d)/

# 或导出为 JSON
pnpm run export:db --output backup.json
```

### 支持 API 密钥轮换吗？

是的，可以配置多个 API 密钥实现轮换和容错：

```env
OPENAI_API_KEY=key1,key2,key3
OPENAI_API_KEY_STRATEGY=round_robin
```

## 使用问题

### 为什么搜索结果不准确？

1. 确认 API 密钥配置正确
2. 检查网络连接
3. 尝试更换搜索关键词

如需更好结果，考虑：
- 使用 Claude 引擎（推理能力更强）
- 在技能配置中调整搜索参数

### 如何添加自定义技能？

```bash
# 创建技能目录
mkdir -p skills/my-skill

# 创建技能文件
cat > skills/my-skill/SKILL.md << 'SKILL'
---
name: my-skill
description: 自定义技能说明
---

技能详细说明...
SKILL
```

### 支持多账户吗？

是的。通过交易记录管理支持：
- 多个券商账户
- 不同资产分类
- 独立收益统计

### 如何导出分析报告？

```bash
# 导出为 PDF
pnpm run report:export --format pdf

# 导出为 Excel
pnpm run report:export --format xlsx
```

## 故障排除

### 启动失败怎么办？

检查以下项：
1. Node.js 版本是否 >= 18
2. 依赖是否完整安装
3. 端口 3000 是否被占用

```bash
# 查看详细日志
DEBUG=* pnpm dev

# 检查端口
lsof -i :3000
```

### AI 响应很慢？

可能原因：
- API 密钥额度不足
- 网络延迟
- 模型负载高

建议：
1. 检查 API 账户余额
2. 使用更快的模型（如 GPT-3.5-turbo）
3. 启用本地缓存
