## v0.19.0 (最新)

### 新功能
- ✈️ 新增生产可用的飞书 WebSocket 文本渠道：基于飞书开放平台官方 SDK 的长连接接入企业自建机器人，支持私聊/群聊白名单（群聊需 @提及机器人）、消息去重与会话串行处理
- 💬 飞书回复以交互式 Markdown 卡片发送，过长自动截断并提示；会话历史持久化，支持 `/clear` 指令清空上下文
- ⚙️ 设置页支持飞书渠道配置：启用开关、App ID/密钥（密钥不回传不落日志）、域名与私聊/群聊白名单，并支持扫码授权自动注册机器人
- 🔍 交易记录搜索支持按股票代码（symbol）过滤
