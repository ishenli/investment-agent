## 环境要求

- Node.js 18+
- pnpm（推荐）或 npm
- **macOS** 11+（桌面应用）/ 任意操作系统（Web 应用）

## 克隆与安装

```bash
git clone https://github.com/ishenli/investment-agent.git
cd investment-agent
pnpm install
```

## 启动

```bash
# 启动 Web 开发服务器（支持所有操作系统）
pnpm dev
# 访问 http://localhost:3000

# 启动 Electron 桌面应用（仅 macOS）
pnpm electron:dev
```

## 配置

所有配置均在应用的**设置页面**完成，包括：
- AI 模型配置（OpenAI、Anthropic）
- 数据源配置（Finnhub、Tavily）
- 渠道配置（微信）

详细的配置说明请参阅 [配置指南](/configuration/)。

## 常用命令

| 命令 | 说明 |
|---------|------|
| `pnpm dev` | 启动 Web 开发服务器 |
| `pnpm build` | 构建 Web 生产版本 |
| `pnpm start` | 启动 Web 生产服务器 |
| `pnpm electron:dev` | 启动 Electron 开发模式（macOS） |
| `pnpm electron:build:pack` | 构建并打包 macOS 安装包 |

桌面应用安装说明请参阅 [Electron 桌面应用](/electron/)。
