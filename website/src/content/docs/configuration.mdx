Investment Agent 的所有配置均可在应用的**设置页面**完成，无需手动编辑配置文件。

## 配置入口

<Steps>
1. **打开设置页面**
   在应用左侧导航栏点击 **设置** 图标

2. **选择配置类别**
   - **AI 模型配置**：配置 OpenAI、Anthropic 等 AI 服务
   - **数据源配置**：配置股票行情、网络搜索等数据服务
   - **渠道配置**：配置微信、飞书等通信渠道
</Steps>

## 渠道配置

### 微信渠道

通过腾讯 iLink 接入个人微信账号，使用**长轮询**模式收发消息：

<CardGrid>
  <Card title="配置项" icon="settings">
    - **Bot Token**：`WEIXIN_TOKEN`
    - **Account ID**：`WEIXIN_ACCOUNT_ID`
    - **API Base URL**：`WEIXIN_BASE_URL`（默认 `https://ilinkai.weixin.qq.com`）
  </Card>
  <Card title="使用说明" icon="message">
    1. 在设置页 → 渠道 → 微信个人号中扫码登录，或手动填凭证
    2. 点击保存配置，服务自动连接
    3. 开始在微信中接收和回复消息
  </Card>
</CardGrid>

### 飞书渠道

通过飞书开放平台官方 SDK 建立 **WebSocket 长连接**，以机器人与你对话：

<CardGrid>
  <Card title="配置项" icon="settings">
    - **App ID**：`FEISHU_APP_ID`
    - **App Secret**：`FEISHU_APP_SECRET`（仅本地存储）
    - **平台**：`FEISHU_DOMAIN`（`feishu` / `lark`）
    - **白名单**：`FEISHU_ALLOWED_USERS`（私聊 open_id）、`FEISHU_ALLOWED_CHATS`（群聊 chat_id）
  </Card>
  <Card title="使用说明" icon="message">
    1. 在设置页支持**扫码创建机器人**，或手动填写凭据
    2. 配置至少一个私聊或群聊白名单
    3. 保存后渠道自动重连生效
  </Card>
</CardGrid>

完整的渠道接入指引请参阅 [渠道接入](/channels/)。

## 数据存储

### 数据库位置

所有数据存储在本地 SQLite 数据库中：

| 平台 | 数据目录 |
|------|---------|
| macOS | `~/Library/Application Support/ig/` |
| Web 应用 | 项目目录下的 `data/` 文件夹 |

<details>
<summary>**自定义数据目录**</summary>

通过环境变量 `INVESTMENT_AGENT_DATA_DIR` 指定数据存储位置：

```bash
# macOS
export INVESTMENT_AGENT_DATA_DIR=/path/to/your/data
```

此配置对 Electron 桌面应用和 Web 应用均有效。

</details>

## 数据备份与恢复

### 备份数据

在设置页面可以导出所有数据：

1. 进入 **设置 → 数据管理**
2. 点击 **导出数据**
3. 选择导出格式（JSON/SQLite）
4. 选择保存位置

### 恢复数据

1. 进入 **设置 → 数据管理**
2. 点击 **导入数据**
3. 选择之前导出的备份文件
4. 确认导入

### 手动备份

如需手动备份数据库文件：

```bash
# 备份数据目录
cp -r ~/Library/Application\ Support/ig/ backup/ig_$(date +%Y%m%d)/
```

## 常见问题

<details>
<summary>**配置保存后未生效？**</summary>

尝试刷新页面或重启应用。如仍有问题，检查浏览器控制台是否有错误信息。
</details>

<details>
<summary>**如何查看当前配置？**</summary>

在设置页面顶部可以看到当前所有已配置服务的状态指示器。
</details>

<details>
<summary>**配置数据存储在哪里？**</summary>

配置信息加密存储在本地 SQLite 数据库中，不会上传到云端。
</details>
