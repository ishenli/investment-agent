# 技术分析

当用户询问股价走势、买卖时机或图表信号时，请从以下技术分析维度展开。

## 分析维度

### 1. 趋势判断（多周期）

- 当前趋势方向（上涨/下跌/震荡）
- 主要均线排列（MA5/MA10/MA20/MA60/MA120）
- 趋势线与通道边界
- **多周期验证**：日线、周线、月线趋势是否一致

### 2. 关键价位

- 近期支撑位与阻力位
- 前高/前低位置
- 缺口位置
- 斐波那契关键回撤位（若适用）

### 3. 技术指标

- **MACD**：金叉/死叉、背离信号（顶背离/底背离）
- **RSI**：超买(>70)/超卖(<30)区域及背离
- **布林带**：收口/开口、触碰上下轨的放量情况

### 4. K线形态

- 常见反转形态（头肩顶/底、双顶/底）
- 持续形态（三角形、旗形、楔形）

### 5. 量价结构（重点）

- **OBV（能量潮）**：与股价趋势是否一致，识别隐性背离
- **成交量柱形态**：
  - 放量突破阻力位（买入信号增强）
  - 缩量回调至支撑位（洗盘概率）
  - 放量滞涨（派发风险）
- **大单资金流**：主动买入/卖出大单占比、净流入/净流出持续性
- **量价形态识别**：
  - 吸筹期：低位缩量盘整 → 温和放量上涨
  - 拉升期：量价齐升
  - 派发期：高位放量滞涨 → 缩量阴跌
  - 洗盘期：快速放量下跌后迅速缩量企稳

## 分析框架

### 多周期验证规则

技术分析必须先看大周期再看小周期，大周期决定方向，小周期决定节奏：

| 周期 | 作用 | 优先度 |
|------|------|--------|
| 月线 | 判断中长期趋势方向 | 最高 |
| 周线 | 判断中期支撑/阻力 | 高 |
| 日线 | 判断短期买卖点 | 中 |
| 60分钟/15分钟 | 精确进场时机（仅辅助） | 低 |

**规则**：
- 月线趋势向上 → 日线回调是低吸机会
- 月线趋势向下 → 日线反弹是减仓机会
- 多周期共振（日线+周线+月线同向）→ 信号最可靠

### 信号强度分级

| 信号强度 | 条件 |
|---------|------|
| **强** | 价格突破 + 成交量放大 + 指标共振 + 多周期一致 |
| **中** | 两个条件满足 |
| **弱** | 仅一个条件满足，需等待确认 |

### 量价背离警示

- **顶背离**：价格创新高 + MACD/RSI/OBV 未创新高 → ⚠️ 回调风险
- **底背离**：价格创新低 + MACD/RSI/OBV 未创新低 → ⚡ 反弹机会

## 示例

### 输入
> "贵州茅台最近走势怎么样？技术面有什么信号？"

### 输出

#### 趋势概览
- 当前趋势：上涨趋势中的高位震荡
- 多周期一致性：月线↑、周线↑、日线震荡
- 趋势强度：中等（大周期向上，小周期整理）

#### 关键价位表

| 价位类型 | 价格区间 | 有效性评估 |
|---------|---------|-----------|
| 强阻力位 | 1,850-1,900 | 前期多次触及回落 |
| 弱阻力位 | 1,780 | 近期高点 |
| 当前价格 | 1,720 | |
| 弱支撑位 | 1,650 | MA20 附近 |
| 强支撑位 | 1,580-1,600 | MA60 + 前期平台 |

#### 技术指标状态

| 指标 | 当前值 / 状态 | 信号含义 |
|------|--------------|---------|
| MA 排列 | 日线 MA5/10/20 交织 | 短期方向不明 |
| MACD | 零轴上方死叉 | 短期调整信号 |
| RSI(14) | 52 | 中性，无超买超卖 |
| 布林带 | 中轨附近，收口 | 震荡中选择方向 |
| OBV | 与价格同步 | 无背离 |

#### 量价分析
- 成交量：近一周较前期萎缩约 15%
- 量价配合：缩量震荡，抛压有限
- 资金状态：北向资金小幅净流出
- 量价阶段：高位缩量整理，疑似洗盘

#### 信号汇总

| 信号类型 | 判断 | 强度 | 依据 |
|---------|------|------|------|
| 趋势信号 | 偏多 | 中 | 月线/周线多头排列 |
| 动量信号 | 中性 | 弱 | MACD 死叉但 RSI 中性 |
| 量价信号 | 中性偏多 | 中 | 缩量整理，抛压有限 |
| K线形态 | 中性 | 弱 | 无明显形态 |

#### 风险提示
- 短期需关注 1,650 支撑能否守住，若跌破可能进一步回踩 1,600
- MACD 死叉尚未修复，短期或延续震荡
- 若放量突破 1,780，则重拾升势概率增大
- **策略方向**：持仓者可继续持有，破位 1,600 考虑减仓；未持仓者建议等待方向明朗

## 注意事项

1. **技术分析的前提**：技术信号在流动性好、交易活跃的品种上更有效
2. **不预测绝对价格**：只给出支撑位/阻力位区间和概率判断
3. **避免绝对化**：不使用"一定会涨/跌"，改用"概率偏大/偏小"或"关注某价位得失"
4. **量价优先**：价格信号若无量能配合，可靠性大幅下降
