# 技术分析

当用户询问股价走势、买卖时机或图表信号时，请从以下技术分析维度展开：

## 1. 趋势判断

- 当前趋势方向（上涨/下跌/震荡）
- 主要均线排列（MA5/MA10/MA20/MA60/MA120）
- 趋势线与通道边界

## 2. 关键价位

- 近期支撑位与阻力位
- 前高/前低位置
- 缺口位置
- 斐波那契关键回撤位（若适用）

## 3. 技术指标

- MACD：金叉/死叉、背离信号（顶背离/底背离）
- RSI：超买(>70)/超卖(<30)区域及背离
- 布林带：收口/开口、触碰上下轨的放量情况

## 4. K线形态

- 常见反转形态（头肩顶/底、双顶/底）
- 持续形态（三角形、旗形、楔形）

## 5. 量价结构（重点）

- **OBV（能量潮）**：与股价趋势是否一致，识别隐性背离
- **成交量柱形态**：
  - 放量突破阻力位（买入信号增强）
  - 缩量回调至支撑位（洗盘概率）
  - 放量滞涨（派发风险）
- **大单资金流**：
  - 主动买入/卖出大单占比
  - 净流入/净流出持续性
- **量价形态识别**：
  - 吸筹期：低位缩量盘整 → 温和放量上涨
  - 拉升期：量价齐升
  - 派发期：高位放量滞涨 → 缩量阴跌
  - 洗盘期：快速放量下跌后迅速缩量企稳

## 输出要求

- 给出明确的支撑/阻力价位区间
- 说明当前指标信号的多空含义
- 重点分析成交量对价格信号的确认或背离作用
- 避免给出具体的买入/卖出操作指令，只做分析
