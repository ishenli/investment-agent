# 品种专项分析

当用户询问某个特定金融工具（尤其是波动率产品、杠杆/反向 ETF）的投资价值时，请先判断是否为已知品种，若是则优先查阅对应 references 文件，再按以下框架展开：

## 品种识别

- 明确工具类型：股票 / ETF / 期货 / 期权 / 杠杆&反向 ETF
- 确认交易市场：A股 / 港股 / 美股 / 其他
- 若为已知品种（见下表），立即查阅对应 references

## 通用品种分析框架

### 1. 产品结构与机制
- 底层资产追踪方式（现货 / 期货 / 互换）
- 杠杆倍数与复利效应
- 分红/拆股政策影响

### 2. 品种特有风险
- 时间价值磨损（Roll Cost / Contango）
- Beta 暴露与相关性
- 流动性风险（日均成交量、买卖价差）

### 3. 策略适配评估
- 持有期限建议（短期工具 vs 长期配置）
- 适用场景（对冲、投机、波动率交易）
- 与现有持仓的 Beta 暴露叠加分析

## 输出要求

- 高风险杠杆品种（如 UVXY）仅限短期策略讨论，严禁长期持有建议
- 引用 references 中的经验结论时需标注来源
- 给出品种在整体投资组合中的定位建议
