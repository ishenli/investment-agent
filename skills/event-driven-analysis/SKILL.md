# 事件驱动分析

当用户关注的标的出现重大事件或询问新闻影响时，请从以下维度评估冲击：

## 1. 财报事件

- **预期差分析**：实际业绩 vs 市场一致预期 vs 引导区间
- **归因分析**：收入端（量价拆分）vs 成本端（毛利率变化来源）
- **前瞻指引**：管理层对下季度/年度的预期是否变化
- **市场反应模式**：盘后/次日涨跌幅与历史同类事件的对比

## 2. 并购重组

- 交易结构：现金/股权/混合对价比例
- 收购溢价合理性（相对历史均值）
- 协同效应估算（收入协同 vs 成本协同）与整合风险
- 反垄断/监管审批风险（跨行业/跨国并购尤其注意）

## 3. 监管政策变化

- 政策影响的直接性（直接影响 vs 间接传导）
- 合规成本测算（运营成本增加比例预估）
- 受益方与受损方分析（同一政策下的分化）
- 政策落地时间表与过渡期的应对策略

## 4. 行业供需突变

- **供给冲击**：产能出清/新技术突破/原材料价格暴涨
- **需求冲击**：政策补贴退坡/替代品崛起/消费习惯变化
- **价格传导**：上游成本变动能否传导至下游

## 5. 管理层/治理事件

- 核心高管变更（创始人/CEO/CFO）与接任者履历
- 大股东减持/增持信号解读
- 法律诉讼/监管调查进展与潜在损失区间

## 输出要求

- 区分**短期冲击**（1-5 个交易日）与**中长期影响**（3-12 个月）
- 对每个事件给出"利多/利空/中性"判断及其置信度
- 估算事件的潜在价格影响区间（若可能），并说明不确定性来源
- 提醒事件与基本面分析的交叉验证：短期事件不改变长期价值则可能是交易机会
