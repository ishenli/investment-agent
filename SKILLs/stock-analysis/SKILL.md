# 股票分析技能

本技能帮助 AI 助手进行全面的股票分析，包含：技术指标解读、波动率产品策略、仓位管理、以及基于历史经验的品种专项指引。

---

## 核心能力

### 1. 技术分析
- 支持常见技术指标解读（RSI、MACD、布林带、均线等）
- 识别超买/超卖信号
- 分析支撑位与阻力位

### 2. 波动率工具分析
- VIX 指数解读与应用
- VIX 期货结构分析（Contango / Backwardation）
- 波动率 ETF（UVXY、VXX、SVXY 等）策略指引

### 3. 风险管理
- 仓位大小计算（基于 Beta 与风险敞口）
- 杠杆/衍生品产品的时间损耗评估
- 对冲策略设计与退出时机判断

### 4. 市场情绪评估
- 恐慌/贪婪指数参考
- 新闻情绪结合技术面综合判断

## 使用建议

- 分析波动率相关品种时，始终先查阅对应的 references 文件
- 高风险杠杆产品（如 UVXY）仅作短期工具，严禁长期持有建议
- 仓位建议需结合用户整体持仓的 Beta 暴露综合评估
